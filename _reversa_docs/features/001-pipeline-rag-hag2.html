📌 Visão Geral da Feature

Implementação completa do pipeline RAG, incluindo os 3 pilares fundamentais: Ingestão de Documentos (PDF/Chunking), Armazenamento Vetorial (SQLite-vec) e Síntese grounded com citações rastreáveis.

🛠️ Comandos da CLI (`anchor-rag`)

# Ingestão recursiva de documentos PDF
anchor-rag ingest --path ./docs/ --chunk-size 500 --overlap 50

# Consulta RAG com ancoragem estrita e citações
anchor-rag query "Quais são as políticas de segurança do sistema?" --top-k 5

# Execução do benchmark quantitativo
anchor-rag eval --output-format json
