📖 Glossário do Domínio & Conceitos do RAG

RAG (Retrieval-Augmented Generation)

Técnica que combina busca de dados relevantes em uma base vetorial (Retrieval) para subsidiar e ancorar a resposta de um modelo de linguagem (LLM Generation).

Dense Embedding

Vetor numérico contínuo (ex: 1536 dimensões no OpenAI text-embedding-3-small) que mapeia o significado semântico do texto em um espaço vetorial.

SQLite-vec

Extensão leve C/C++ para SQLite que habilita busca vetorial nativa via tabela virtual vec0 sem necessidade de infraestrutura pesada externa.

Chunking com Sliding Window

Divisão de documentos PDF em pedaços de texto (chunks) com tamanho máximo e sobreposição (overlap) baseada em tokens (via tiktoken) para preservar o contexto.

Strict Grounding (Ancoragem Estrita)

Diretiva de prompt no LLM que exige responder estritamente com base nos fatos dos chunks fornecidos e citar explicitamente as fontes com tags [N].

Recall@k e MRR

Métricas de avaliação de informação: Recall@k mede se o documento relevante estava nos top-k resultados; MRR mede a posição recíproca do primeiro resultado relevante.
